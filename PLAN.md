# Split: personal website plan

_Draft prepared with AI assistance: review before using._

## 1. Purpose
Fill these in first. They drive every other decision.
- **Who is it for?** (recruiters, peers, clients, friends)
- **What should a visitor do after reading?** (contact me, read my work, connect on LinkedIn)
- **One-line summary of me:** _e.g. "Product manager building tools for vocational education."_

## 2. Structure
Start with a single page. Split into separate pages only once a section gets long.

| Section | Content | Status |
|---|---|---|
| Hero | Name, one-line summary, photo (optional) | ☐ |
| About | 2–3 short paragraphs: what you do, how you got here, what you care about | ☐ |
| Work / Projects | 3–5 highlights: title, one-sentence outcome, link | ☐ |
| Writing (optional) | Links to posts or talks | ☐ |
| Contact | Email link, LinkedIn, GitHub | ☐ |

## 3. Content checklist
- [ ] Headshot (square, about 400×400 px, under 200 KB)
- [ ] Short bio (about 50 words) and long bio (about 150 words)
- [ ] Project list with links
- [ ] Social links
- [ ] Decide whether to show an email address publicly (or use a contact form service)

Note: keep employer and client details generic unless you have approval to name them.

## 4. Design
- **Colours:** pick one accent colour, change `--accent` in `styles.css`
- **Font:** system font stack by default; swap in a Google Font if you want
- **Tone:** _e.g. clean and minimal / warm and personal / bold_
- Sites I like for reference: _add 2–3 links_

## 5. Build steps
1. Edit the placeholder text in `index.html`
2. Open `index.html` in a browser to preview (double-click it)
3. Adjust colours and spacing in `styles.css`
4. Check it on a phone-sized window
5. Publish (below)

## 6. Hosting (free options)
- **GitHub Pages:** push the folder to a repo, turn on Pages in repo settings
- **Netlify / Cloudflare Pages:** drag and drop the folder
- **Custom domain (optional):** about AUD 15–30 a year for a .com or .com.au
